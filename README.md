# College Attendance Management System (MERN)

Features:
- Dashboard
- Student management
- Faculty management
- Subject management
- Mark Present/Absent attendance
- Attendance records
- Student-wise reports
- Low attendance (<75%) list
- No login/register/logout

## Requirements
- Node.js
- MongoDB Community Server running locally
- VS Code

## Run backend
cd backend
copy .env.example .env
npm install
npm run dev

## Run frontend
Open another terminal:
cd frontend
npm install
npm run dev

Frontend: http://localhost:5173
Backend: http://localhost:5000
